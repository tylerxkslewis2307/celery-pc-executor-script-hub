## About Celery

Celery is a Windows desktop application for Roblox Lua injection and script execution. Its compact interface is intended for users who want to load and run scripts on a Windows PC without dealing with an unnecessarily complex setup.

Alongside its execution workflow, Celery provides a 500+ entry script hub, batch running, SQLite-backed queue persistence, and an automatic update system. This combination places it among tools commonly described as Roblox executors, Lua executors, script hubs, and Windows script executors.
